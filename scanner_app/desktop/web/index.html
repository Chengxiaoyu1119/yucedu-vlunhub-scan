关于

靶场扫描助手 v2.0 · macOS / Windows

双模式靶场信息收集工具：

  • 公网 Web 靶场 — ICMP 存活探测、端口递增扫描、HTTP/HTTPS 首页抓取、Playwright 首页截图
  • 内网穿透靶场 — ICMP + TCP 存活发现、TTL / 端口指纹 / SSH Banner 多信号系统判断（无需凭据）

每次扫描自动生成分类报告：report.html（内嵌截图）/ report.md / report.csv / report.json。

  • 命令行：python3 -m scanner_app.cli.public
  • 图形界面：macOS 双击 launchers/启动靶场扫描.command，Windows 双击 launchers/启动靶场扫描.vbs

仅用于授权靶场环境的安全教学与测试；内网模式不做爆破、不登录、不利用漏洞。
